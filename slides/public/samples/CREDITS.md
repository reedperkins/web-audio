# Sample credits

All clips are mono 96 kbps MP3, re-encoded with ffmpeg. They're served from
`public/`, so the deck needs no network to play them.

| File | Source | License | Changes |
|---|---|---|---|
| `small-step.mp3` | Apollo 11, "That's one small step for man…", [NASA](https://www.nasa.gov/wp-content/uploads/2015/01/590331main_ringtone_smallStep.mp3) | Public domain (NASA media) | mono |
| `drum-loop.mp3` | "Tribe Drum Loop" by PearceWilsonKing, [Freesound #342465](https://freesound.org/people/PearceWilsonKing/sounds/342465/) | CC0 1.0 | mono (from the HQ preview) |
| `piano-c4.mp3` | Salamander Grand Piano V3 (C4) by Alexander Holm, via [Tone.js audio](https://tonejs.github.io/audio/salamander/C4.mp3) | CC BY 3.0, credit required | trimmed to 4 s with a fade, mono |
| `hello.mp3` | macOS `say` text-to-speech voice | — | mono |

Other CC0 drum loops considered (in the agent scratchpad, not vendored):
Freesound #211869 "110_loop" by wikbeats, #232335 "Slow Drum Loop" by Leifgreen.
